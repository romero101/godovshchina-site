# Тест-кейсы сайта polis-godovshchina.ru

Версия 7 сентября 2026. Порядок — как идёт человек с рекламы: от загрузки страницы до покупки у партнёра.
Для каждого кейса: шаги → что должно быть. Отмечать результат по матрице устройств в конце.

## 1. Загрузка страницы
1.1. Открыть https://polis-godovshchina.ru/strahovka-ipoteki-sberbank/ на телефоне по мобильной сети → первый экран виден за 2 с, без прыжков вёрстки, калькулятор в первом экране на телефоне.
1.2. Консоль браузера без ошибок; подключены calc.js?v=13 и metrika.js?v=3.
1.3. Плашка про cookie показана один раз; после «Понятно» не появляется при перезагрузке.
1.4. Открыть с рекламной меткой `?utm_source=yandex&utm_medium=cpc&utm_campaign=search_banks` → страница та же, метка не ломает вёрстку, в Метрике визит помечен источником «Яндекс Директ».
1.5. Ссылка без слеша на конце (`/strahovka-ipoteki-vtb`) → редирект 301 на вариант со слешем.
1.6. Несуществующий адрес → своя страница 404 с ссылками на главную и калькулятор.

## 2. Калькулятор «полис или надбавка» (первый экран)
2.1. Изменить остаток вводом цифр → сумма форматируется с пробелами, ползунок двигается, результат пересчитывается сразу.
2.2. Ползунок → поле остатка обновляется.
2.3. Возраст 18, 35, 70 → цена растёт с возрастом; вне диапазона (17, 71) значение не принимается или ограничивается.
2.4. Пол «Женщина» → цена ниже, чем «Мужчина» при тех же данных.
2.5. Надбавка банка (где есть поле) → вывод «выгоднее полис / выгоднее надбавка» меняется при крайних значениях.
2.6. Остаток 100 000 и 50 000 000 → без ошибок, без «NaN», без бесконечных чисел.

## 3. Кнопка «Показать точные цены … страховых» под калькулятором
3.1. Ввести остаток 2 500 000, возраст 40, «Мужчина», нажать кнопку → открывается НОВАЯ вкладка polis812.ru/mortgage/companies; в адресе partnerId=212866; в выдаче банк соответствует странице (Сбер на странице Сбера, ВТБ на странице ВТБ), остаток 2 500 000, пол мужской, возраст 40 (дата рождения примерно 40,5 года назад).
3.2. Та же кнопка с заблокированными всплывающими окнами (Safari по умолчанию, режим «Строгий» в Яндекс Браузере) → выдача открывается в ТОЙ ЖЕ вкладке, а не «ничего не происходит».
3.3. Повторный ввод данных не требуется: форма ниже на странице уже заполнена остатком и датой рождения с калькулятора.
3.4. В Метрике после клика зафиксирована цель «Переход к партнёрскому калькулятору» (проверка: открыть сайт с `?_ym_debug=1`, в консоли видно reachGoal partner_click).
3.5. Выдача Полис812 показывает цены не позже чем через 10 с; если дольше — засечь время и указать устройство. Это медленность партнёра, а не наша, но фиксируем.

## 4. Форма «Показать цены для моей ипотеки» (блок «Оформить»)
4.1. Открыть страницу заново, ничего не трогая в калькуляторе → в форме остаток 3 000 000 и дата рождения, соответствующая возрасту по умолчанию.
4.2. Изменить дату рождения вручную → она не перезаписывается при смене возраста в калькуляторе.
4.3. Очистить дату, нажать «Показать цены страховых» → подсказка «укажите дату рождения», фокус в поле, вкладка партнёра не открывается.
4.4. Заполненная форма, нажать кнопку → новая вкладка партнёра, параметры совпадают с формой (банк страницы, остаток, пол, дата).
4.5. На странице /kalkulyator-strahovaniya-ipoteki/ выбрать в форме другой банк (например, Дом.РФ) → в выдаче партнёра именно этот банк.
4.6. Остаток меньше 100 000 или больше 50 000 000 → при потере фокуса поле само ограничивается.
4.7. Кнопка после клика не остаётся «серой» навсегда: повторный клик снова открывает партнёра.

## 5. Окно партнёра на странице (кнопка «Открыть окно партнёра», страницы Сбера и калькулятора)
5.1. Нажать → под кнопкой появляется рамка с калькулятором Полис812, кнопка меняет текст на «Загружаем…», затем окно рабочее.
5.2. В окне партнёра посчитать цену → таблица цен видна внутри страницы, кнопки «Купить» ведут на polis812.ru.
5.3. Если окно не загрузилось за 15 с → работает ссылка «откройте его в новой вкладке» и ссылка «калькулятор Пампаду».

## 6. Напоминание в календарь
6.1. Указать дату окончания полиса, нажать «Напомнить» → скачивается файл .ics.
6.2. Открыть файл на iPhone (Календарь) и на Android (Google Календарь) → событие за 2 недели до даты с уведомлением, текст без кракозябр.
6.3. В Метрике цель «Напоминание в календарь».

## 7. Калькулятор остатка долга (/ostatok-dolga/)
7.1. Сумма 3 000 000, ставка 10 %, 20 лет, старт год назад → остаток меньше суммы и больше нуля, платёж около 28 950 ₽.
7.2. Дата раньше старта или ставка 0 → нет «NaN», понятное сообщение или ноль.
7.3. Кнопка «Подставить в калькулятор» (если есть) → остаток переносится на страницу банка.

## 8. Навигация и страницы
8.1. Главная → «Все банки» → страница банка → «Аккредитованные страховые» → страница страховой: все ссылки ведут на существующие страницы, хлебные крошки верные.
8.2. На каждой странице банка есть форма расчёта со своим банком (проверить 3 случайных: ВТБ, Альфа, Т-Банк).
8.3. Мобильное меню открывается и закрывается, ссылки кликабельны большим пальцем.
8.4. Картинки не выходят за экран, таблицы цен прокручиваются по горизонтали, а не ломают страницу.
8.5. Футер: оператор «ИП Роман, ИНН», ссылка на политику, политика открывается.

## 9. Аналитика и реклама
9.1. Открыть объявление из Директа (или ссылку из отчёта с utm) → посадочная соответствует группе: ВТБ → /strahovka-ipoteki-vtb/, калькулятор → /kalkulyator-strahovaniya-ipoteki/ и т. д.
9.2. Цепочка целей за один визит: partner_click → (после появления бэкенда) offers_shown → partner_buy. Проверить в Метрике «Посетители» по своему визиту.
9.3. В кабинете Полис812 переход виден с меткой utm_source=godovshchina и партнёром 212866 в течение суток.
9.4. Вебвизор записывает визит с рекламы, запись открывается.

## 10. Бэкенд цен (после развёртывания api.polis-godovshchina.ru)
10.1. `curl -X POST https://api.polis-godovshchina.ru/quote.php` с JSON из README → ответ ok:true, список страховых с ценами.
10.2. На сайте нажать «Показать цены страховых» → таблица цен под формой за 3 с, вкладка партнёра НЕ открывается автоматически; кнопки «Купить» открывают партнёра и фиксируют цель partner_buy.
10.3. Выключить бэкенд → кнопка снова открывает партнёра сразу, без зависания «Считаем цены…».
10.4. Запрос без Origin сайта или чаще 30 раз в минуту → отказ, сайт от этого не ломается.
