Версия 3 от 7 сентября 2026. Источник правды — этот файл и чек-лист с чекбоксами (артефакт «Тест-кейсы Годовщины»), они меняются вместе; версия растёт при каждом изменении, запись в истории ниже.

Приоритет: **К** критично (без этого нет денег), **В** важно, **Ж** желательно. Режим: **авто** гоняет скрипт , **руками** проходит Роман.
