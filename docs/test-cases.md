# Тест-кейсы сайта polis-godovshchina.ru

Версия 4 от 7 сентября 2026. Файл сгенерирован из `docs/test-cases.html` (единый источник: из него же публикуется чек-лист с чекбоксами «Тест-кейсы Годовщины»). Правки вносить в HTML, затем `node tools/gen_testcases.mjs`.

Приоритет: **К** критично (выкладка запрещена, пока не зелёные), **В** важно, **Ж** желательно. Режим: **авто** гоняет `tests/e2e/run.mjs`, **руками** проходит Роман. Когда: **релиз** перед каждой выкладкой, **месяц** раз в месяц, **разово** один раз и после изменения соответствующей части.

Тестовые данные: остаток 2 500 000 ₽, возраст 40, мужчина, дата рождения 15.03.1986, банк той страницы. Второй набор: 1 200 000 ₽, 29 лет, женщина.

Прогон: `tools/release.sh` (локальная сборка → критические → push → дымовой прогон на живом), `MODE=monthly node tests/e2e/run.mjs` раз в месяц.

## Матрица окружений

Ключевые кейсы: 3.1, 3.7; расширенный ряд только 3.1. Строки A, D, F закрывает автопрогон. Состав рядов пересматривается раз в месяц по отчёту Метрики «Технологии → Браузеры».

**Обязательные: основной трафик из Директа в России**

- **A.** Android, Chrome, телефон Xiaomi или Samsung, ширина 360 px — авто (эмуляция)
- **B.** Android, Яндекс Браузер с включённой «Защитой» — блокирует всплывающие окна и трекеры
- **C.** Android, встроенный браузер приложения Яндекс (с Алисой) — так открываются объявления Директа из приложения
- **D.** iPhone, Safari, iOS 17–18 — авто (эмуляция WebKit); руками: всплывающие окна заблокированы по умолчанию
- **E.** iPhone, приложение Яндекс или Яндекс Браузер — второй по массовости путь с iPhone из Директа
- **F.** Windows, Chrome, экран 1366×768 — авто (эмуляция)
- **G.** Windows, Яндекс Браузер с «Защитой» — доля на ПК в России сопоставима с Chrome
- **H.** Windows, Chrome с AdGuard или uBlock Origin — режут партнёрские ссылки и Метрику

**Расширенные: только 3.1, и только когда браузер появился в отчёте Метрики**

- **I.** Android, Samsung Internet с блокировщиком — у Samsung свой браузер по умолчанию
- **J.** Android, Huawei Browser (без сервисов Google) — старый движок WebView
- **K.** Android 9–10, старый WebView — телефоны 2019–2020 годов
- **L.** Встроенный браузер Telegram и VK — если поведём трафик из соцсетей
- **M.** Mac, Safari — строгая защита от трекинга
- **N.** ПК, Firefox с усиленной защитой
- **O.** Windows с Kaspersky Protection в браузере — блокирует всплывающие окна и редиректы
- **P.** Любой браузер, инкогнито — нет localStorage и cookie
- **Q.** Любой браузер, медленная сеть 3G и обрыв связи — окно партнёра и выдача
- **R.** Любой браузер через VPN с зарубежным IP — партнёр может блокировать иностранные адреса
- **S.** Тёмная тема и шрифт 150 % — читаемость и вёрстка
