# Годовщина — сайт для SEO-теста

Статический сайт без сборки: три посадочные страницы под ипотеку Сбербанка и калькулятор «полис или надбавка».

## Структура

```
index.html                              — хаб со ссылками на три страницы
strahovka-ipoteki-sberbank/index.html   — главная посадочная + калькулятор
strahovanie-zhizni-ipoteka-sberbank/    — страхование жизни (отказ или купить дешевле)
akkreditovannye-strahovye-sberbank/     — список аккредитованных и кто дешевле
assets/style.css, assets/calc.js        — стили и калькулятор
robots.txt, sitemap.xml                 — для Яндекса; замените DOMAIN
```

## Перед выкладкой

1. **Партнёрская ссылка** — уже вписана: `PARTNER_URL` в `assets/calc.js`, Polis812, partnerId 212866
   (сгенерирована в «Инструменты → Конструктор ссылок», продукт «Страхование ипотеки», UTM `godovshchina/site/sber`).
   Проверена: калькулятор открывается с предвыбранным Сбербанком, партнёрская кука ставится.
2. **DOMAIN** — во всех файлах (`canonical`, `robots.txt`, `sitemap.xml`):
   `grep -rl DOMAIN . | xargs sed -i '' 's#DOMAIN#вашдомен.ru#g'`
3. **ИНН и контакты** в подвале каждой страницы — обязательны для агентского сайта.
4. **Метрика** — номер счётчика в `METRIKA_ID` (`assets/metrika.js`). Цель `partner_click`
   (клик по кнопке перехода) создаётся в Метрике как JavaScript-событие с этим идентификатором.
5. **Маркировка рекламы** — Polis812 регистрирует партнёрские ссылки в ЕРИР сам; после выкладки
   добавить домен в конструкторе ссылок («Маркировка рекламы → Добавить сайт»).

При каждом изменении `calc.js` поднимайте версию в `<script src="../assets/calc.js?v=N">` — иначе браузеры отдадут старый файл из кэша.

## Хостинг

Любой статический: reg.ru/timeweb «сайт из файлов», GitHub Pages, Netlify. Загрузить папку целиком.
После выкладки: добавить сайт в Яндекс Вебмастер, указать sitemap, проверить «Турбо/мобильность».
